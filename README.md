# Sistem Manajemen Stok pada Minimarket

Aplikasi web untuk mencatat stok barang minimarket: kelola produk, supplier, purchase order (PO), dan laporan.
Proyek mata kuliah Rekayasa Perangkat Lunak, Kelompok 1, Universitas Indraprasta PGRI.

## Fitur
- Registrasi dan login Admin
- Manajemen produk (tambah, ubah, hapus, cari) dengan penanda stok menipis
- Manajemen supplier dan purchase order (buat, batalkan, terima barang: stok bertambah otomatis)
- Laporan barang masuk dan stok per periode, ekspor ke PDF

## Teknologi
Laravel (PHP) dan MySQL
